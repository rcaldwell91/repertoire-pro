# repertoire-pro
Repertoire Pro — a shared warm-up and exercise app for a coach and their students: Ja Ronn assigns work from his phone, Lyon and Briar see it on theirs.

## Files

- `index.html` — the live build (v10.1). Served at rcaldwell91.github.io/repertoire-pro
- `next.html`  — the test page: v10.1 plus accounts and the coach channel.
- `src/`       — the cloud layer, kept as readable modules.
- `build-next.sh` — rebuilds next.html from index.html + src/. Run it after editing src/.
